# AD Consulting — propuesta corporativa

Sitio corporativo responsive para AD Consulting, desarrollado con Next.js y preparado para desplegarse en Vercel.

## Rutas

- `/` — Inicio corporativo
- `/corporativa` — Inicio corporativo compatible con la propuesta original
- `/corporativa/nosotros` — Nosotros
- `/corporativa/servicios` — Servicios
- `/corporativa/ad50` — AD+50

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```
